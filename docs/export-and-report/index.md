# Export data

Save a ready dataset, keep selected analysis results, or prepare an HTML report.
Choose the workflow that matches what you need to keep:

| What you want to save | Guide |
|---|---|
| The rows and columns in a result tab, including a prepared or combined dataset | [Export a dataset](export-data.md) |
| Tables and charts produced by an analysis, or a report assembled from analysis results | [Export analysis results and reports](analysis-results-and-reports.md) |
| A profile of one dataset or a comparison of open datasets | [Export analysis results and reports](analysis-results-and-reports.md#data-profiling-reports) |

Dataset exports save tabular data in CSV, Excel or a binary data-file format.
Analysis exports save outputs from a successful calculation; an HTML report
collects selected analysis results and notes. These outputs are not substitutes
for one another.

## Find the right workflow

- To save the full dataset, select its ready result tab and use a dataset export.
- To save a table or chart created by an analysis, use that analysis's **Export**
  control. The available results vary by analysis; see
  [Advanced analysis](../analyze-data/index.md#section-guides).
- To assemble several successful analysis results into a shareable document,
  add them to **Reports** and generate an HTML report.
- To inspect or compare datasets with a data profile, use
  **External tools → Data profiling…**.

For the workbench layout and export controls, see
[Workbench window](../workbench/index.md#menu-bar).
