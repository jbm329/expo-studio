# Export data

Save a ready dataset, keep selected analysis results, or prepare an HTML report.
Choose the workflow that matches what you need to keep:

## Choose a task

| Task | Guide |
|---|---|
| Save the rows and columns in a result tab | [Export a dataset](export-data.md) |
| Save tables or charts produced by an analysis, or prepare an HTML report | [Export analysis results and reports](analysis-results-and-reports.md) |
| Profile one dataset or compare open datasets | [Data profiling reports](analysis-results-and-reports.md#data-profiling-reports) |

## How export workflows differ {#export-types}

Dataset exports save tabular data in CSV, Excel or a binary data-file format.
Analysis exports save outputs from a successful calculation; an HTML report
collects selected analysis results and notes. These outputs are not substitutes
for one another.
