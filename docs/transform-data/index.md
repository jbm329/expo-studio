# Transform data

Create or combine result datasets with the workbench's transformation tools.
Choose the operation by the change you want to make:

## Choose a task

| Task | Guide |
|---|---|
| Calculate a new column from existing values | [Derived columns](derived-columns.md) |
| Group rows and calculate summary metrics | [Reshape](reshape.md) |
| Match records between two datasets and add columns | [Join datasets](join.md) |
| Append rows from one dataset to another | [Concatenate datasets](concatenate.md) |

## How transformations affect datasets {#transformation-results}

Derived columns change the current dataset. Reshape, Join and Concatenate
create a new result dataset and leave their source datasets unchanged. Each
guide explains its inputs, behavior and result.
