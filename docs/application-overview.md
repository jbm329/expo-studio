# What you can do with Expo Studio

Expo Studio brings data into one desktop workbench, where you can review,
prepare, analyze and save it. A typical workflow is **get data → prepare →
analyze → export**, but you can start at any step that fits your task.

For the main window, its menus and its editor/result areas, see
[Workbench window](workbench/index.md).

## Get data from different sources {#get-data}

Load tabular data from a database query, a supported local file or a configured
REST request. The [Get data guide](get-data/index.md) explains these workflows
and links to database and REST connection setup.

## Review and understand your data {#review-data}

Inspect a ready result dataset before changing or analyzing it. Start with
[Dataset Overview](analyze-data/overview.md) or
[Statistics](analyze-data/statistics.md), or browse the
[analysis guides](analyze-data/index.md#choose-an-analysis).

## Clean and transform data {#clean-and-transform}

Use the guides for the task you need:

| Task | Guide |
|---|---|
| Sort, rename, remove or reorder columns; clean values or filter rows | [Prepare data](prepare-data/index.md) |
| Create calculated columns, group rows or combine datasets | [Transform data](transform-data/index.md) |

Preparation changes the dataset in its result tab; transformations such as
Reshape create a new result dataset. Each guide describes the behavior of its
operation.

## Combine datasets {#combine-datasets}

For task instructions on joining or concatenating datasets, see
[Transform data](transform-data/index.md).

## Analyze data and share findings {#analyze-and-share}

Choose an analysis in [Advanced analysis](analyze-data/index.md) to inspect a
dataset, compare groups, measure relationships, fit models or explore patterns
over time. Each analysis guide covers its own inputs and results.

To save analysis outputs or assemble an HTML report, see
[Export data](export-and-report/index.md).

## Export prepared data {#export-data}

Save the rows and columns in a result tab, or choose an analysis/report export.
The [Export data section](export-and-report/index.md) explains the available
workflows.

## Continue with the guides {#continue}

Browse the task guides from [Home](index.md#available-guides), or use
[Workbench window](workbench/index.md) to orient yourself in the application.
This overview provides context; detailed instructions live in the guides for
each task.
