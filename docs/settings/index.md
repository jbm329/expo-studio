# Settings

Configure Expo Studio's general preferences, diagnostic logging, database
connections and REST API requests. Choose a guide below for the settings you
want to manage:

## Choose a task

| Task | Guide |
|---|---|
| Set language, documents directory, undo limits or file-processing options | [General settings](general-settings.md) |
| Configure diagnostic log levels and destinations | [Log settings](log-settings.md) |
| Add or manage named database connections | [Database connections](database-connections.md) |
| Configure and test saved REST API requests | [REST API connections](rest-api-connections.md) |

General settings, logging preferences, and saved connections are managed in
separate dialogs. Connection setup and data-loading workflows are documented
in the corresponding connection and [Get data](../get-data/index.md) guides.

## Continue your workflow

- [Get data](../get-data/index.md) to load data with SQL, local files or REST.
- [Workbench window](../workbench/index.md) for the application layout.
- [Home](../index.md#available-guides) for all task guides.
